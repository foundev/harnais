# Harnais

This is a lightweight agentic harness written in Go, similar to pi or Claude Code but smaller in scope and more human sized.

## Roadmap

- sandboxing
- MCP support (Model Context Protocol)
- ACP support (Agent Client Protocol)
- Remote access via a web server
- Integrated web search tooling
- Image support
- @ files to add them to the context
- Openrouter support
- Z.ai subscription support
- Codex subscription support
- Claude API support
- Deepseek API support
